# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private vulnerability reporting for the repository concerned (the "Security" tab, then "Report a vulnerability"). Include what you found, how to reproduce it, and which version.

You can expect an acknowledgement within a few days. Confirmed problems are fixed, and the reporter is credited on request.

## Scope

These projects sign requests, send them, classify responses and verify webhooks. Reports about signing, handling of secrets and personal data, and webhook verification are in scope.

Problems in Selcom's gateway or API are not ours to fix; report those to Selcom through their developer portal at <https://developers.selcommobile.com/>.

## Never post secrets

Do not put real API keys, secrets, PINs, tokens or customer data in issues, pull requests or test fixtures. If a credential was exposed, rotate it with Selcom.
